    Connecteurs

    Reliez vos comptes publicitaires et votre boutique via leurs API officielles.

    Aucun connecteur n'est actif. Les connexions réelles nécessitent l'accès aux API officielles de chaque plateforme. MarketPilot ne simule jamais une connexion : tant qu'un accès n'est pas obtenu, le statut reste « Non connecté ».

    M

    Meta Ads

    Meta Marketing API

    Non connecté

    Dépenses, impressions, CPM, CTR, CPC, clics et vues vidéo de vos campagnes.

    Étapes pour l'activer
    1. Créer une application dans Meta for Developers.
    2. Demander l'accès à la Marketing API (revue Meta).
    3. Autoriser le compte publicitaire (consentement OAuth).
    4. Choisir la campagne à suivre.
    T

    TikTok Ads

    TikTok Marketing API

    Non connecté

    Mêmes indicateurs que Meta pour vos campagnes TikTok.

    Étapes pour l'activer
    1. Créer un compte développeur TikTok for Business.
    2. Demander l'accès à la Marketing API.
    3. Autoriser le compte publicitaire.
    4. Choisir la campagne à suivre.
    S

    Shopify

    API Admin Shopify

    Non connecté

    Commandes, paiements et livraisons pour mesurer les ventes réelles.

    Étapes pour l'activer
    1. Créer une application personnalisée dans votre boutique.
    2. Accorder la lecture des commandes.
    3. Renseigner la connexion dans MarketPilot.
